# 用户手册（学生社团管理系统）

> 课程交付文档（need.md 考核4"用户手册"）。面向系统全部四类角色的使用说明。
> 系统地址：前端 http://localhost:5173（部署方式见 [04-一键启动脚本.md](04-一键启动脚本.md)）。

> 已交付15个页面。Windows可直接使用压缩包中的JAR与前端dist，按根目录README初始化后双击scripts/start-all.bat；停止用scripts/stop-all.bat。页面样例见test/screenshots。原文档冲突及实现边界见08-实现说明与文档差异.md。

## 1 系统简介与角色

学生社团管理系统实现社团从**建团申请、运营管理、活动开展到解散注销**的全生命周期管理。

| 角色 | 说明 | 主要功能 |
| --- | --- | --- |
| 普通学生 | 学号登录 | 浏览社团、申请入社、主动退社、发起建团、查看档案与消息 |
| 社团管理层 | 社团的正/副社长（正副权限一致） | 社员管理、入社审批、晋升/换届、活动申办、公告管理、发起解散（仅社长） |
| 学生会成员 | 可兼任社团身份 | 建团/解散双审批、成员管理、发布系统消息、查看审批记录 |
| 指导教师 | 工号登录 | 建团/解散/活动审批、查看所辖社团数据 |

**账号说明**：账号由系统预置导入（不开放注册），演示账号见 [05-测试文档.md](05-测试文档.md) 第 2 节（初始密码 123456）。

## 2 通用操作

1. **登录**：首页选择身份（学生/教师），输入学号或工号与密码（密码在浏览器内加密后提交）；
2. **系统消息**：右上角"消息中心"查看学生会发布的全体公告（无已读状态，按发布时间倒序）；
3. **社团广场**：浏览正常运营的社团与公告；**已解散的社团即被系统删除，不再展示**；
4. **状态标签含义**：
   - 申请：待审批（橙色）/ 已同意（绿色）/ 已拒绝（红色）
   - 活动：待审批 / 进行中 / 已结束 / 已驳回
   - 角色：社长（红）/ 副社长（橙）/ 普通社员（默认）
5. 所有审批进展均可通过对应页面的状态查看，系统**不做自动消息提醒**。

## 3 普通学生使用指南

### 3.1 申请入社
社团广场 → 目标社团卡片"申请加入"。
- 一次只能有一个待审批申请（有在途申请时系统会提示）；
- 已加入社团的学生不能再申请；正在解散审批中的社团暂停申请；
- 可在"个人中心 → 我的申请"查看审批进度。

### 3.2 主动退社
个人中心 → "退出社团"（二次确认）。退社立即生效、无需审批，系统留痕（时间/类型）。

### 3.3 发起建团
个人中心 → "发起建团"：填写社团名称、简介，选择空闲指导教师，填写**5 名无社团归属学生**的学号（含自己），提交后：
- 等待学生会审批 → 指导教师审批（进度条展示）；
- 双审批全部通过 → 社团自动创建，5 名发起人自动成为社员（第 1 名正社长、第 2~3 名副社长、其余普通社员）；
- 任一方驳回 → 建团失败，可重新发起。

### 3.4 查看个人档案
个人中心 → 我的档案：当前社团与角色、历史入退社记录（主动退社/被踢出）、角色变更记录。

## 4 社团管理层使用指南（正/副社长，权限一致）

### 4.1 社员管理
"我的社团 → 社员管理"：查看在职社员；行内操作——
- **踢出**（社长不可被踢）：立即生效，留痕踢出类型与操作人；
- **晋升/降级**：普通社员 ↔ 副社长（每社最多 1 社长 + 2 副社长，超限会被系统拦截）。

### 4.2 社长换届
"社员管理 → 换届"：一个弹窗内完成——
1. 勾选需降级人员（**必须包含现任社长**，以及需调整的副社长）；
2. 选择新社长（须为本社团在职社员）；
3. 一次提交，系统先降后升、原子完成，并写入两条变更日志。
> 若漏选现任社长，系统会提示"已存在在职正社长"，补充降级名单后重新提交。

### 4.3 入社审批
"我的社团 → 审批台"：对待审批申请点"同意"或"拒绝"。
- 同意 → 学生自动入社；
- 若学生已加入其他社团，同意会被系统拦截并提示（申请保持待审批，请让学生先处理）。

### 4.4 活动管理
"活动管理"：申办（名称/简介/起止时间/地点，**起止时间仅作展示**）→ 等待指导教师审批 → 通过后自动"进行中" → 活动结束后手动"完结"。
> 社团正在解散审批期间不可申办活动。

### 4.5 公告管理
发布/编辑/删除本社团公告；删除为软删除（保留发布记录，社员端不再显示）。

### 4.6 解散申请（仅社长可见）
"解散申请"：提交后等待学生会与指导教师双审批；审批期间**社团暂停入社申请与活动申办**；双通过后社团及全部数据被系统删除，全体社员恢复无社团状态；任一方驳回则流程终止，可重新发起（同一时间仅一条待审批申请）。

## 5 学生会使用指南

1. **建团审批**（工作台 → 建团审批）：查看申请详情（社名、简介、5 名发起人、指定教师），同意/驳回并记录审批人与时间；
2. **解散审批**：同款面板，驳回则解散终止，同意则等待教师终审；
3. **成员管理**：新增/移除学生会成员（**须至少保留一名成员**），所有变动自动写入操作日志；
4. **发布系统消息**：编辑标题与内容发布，全员可见；支持编辑与软删除已发消息；
5. **审批记录**：查询历史建团审批记录（解散记录随社团删除，不保留）。

## 6 指导教师使用指南

1. **建团审批**（工作台）：仅处理指定您为指导教师的申请；同意且学生会已同意 → 系统自动创建社团并分配发起人角色；驳回 → 建团终止；
2. **解散审批**：仅处理所辖社团的解散申请；同意且学生会已同意 → 社团数据被系统删除，您恢复空闲（可再指导新社团）；驳回 → 解散终止；
3. **活动审批**：仅能审批所辖社团的活动；同意 → 活动开始（进行中）；驳回 → 活动终止；
4. **社团数据**：查看所辖社团的信息、社员名单、活动与公告。

## 7 常见提示信息对照表

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 您已加入社团，不可再提交入社申请 | 单社团约束 | 先退社再申请 |
| 您已有待审批的入社申请 | 一个学生同时只能有一个在途申请 | 等待审批结果或联系管理层处理 |
| 该社团正在解散审批中，暂停入社申请 | 解散冻结 | 等待解散流程结束 |
| 该社团已存在在职正社长，不可重复设置 | 1正2副约束 | 换届请使用"换届"功能（先降后升） |
| 该社团在职副社长已达2名上限 | 1正2副约束 | 先降级一名副社长 |
| 仅社团社长可发起解散申请 | 权限 | 请社长操作 |
| 该社团已有待审批的解散申请 | 防重复 | 等待当前申请处理完 |
| 该学生已加入其他社团，审批已回滚 | 唯一键冲突 | 让该学生先退社再重新审批 |
| 学生会至少保留一名成员 | 成员保护 | 先新增成员再移除 |
| 该申请已被处理 | 并发/重复操作 | 刷新页面查看最新状态 |
| 建团申请双审批未全部通过 | 前置条件 | 检查双审批状态 |
| 数据冲突，请刷新后重试 | 唯一键冲突（社名重复/教师被占用等） | 核对信息后重试 |
