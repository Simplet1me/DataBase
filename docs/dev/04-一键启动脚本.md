# 演示脚本

脚本已统一整理到 `demo/`，操作步骤与账号见 [测试手册](../../demo/测试手册.md)。

| 文件 | 用途 |
| --- | --- |
| database_init.bat | 初始化数据库对象及测试数据，已有表时停止 |
| database_reset.bat | 输入 RESET 后删除重建 club_manage 并恢复测试数据 |
| build.bat | 仅编译后端，输出 release/club-manage.jar |
| start.bat | 当前终端运行 java -jar 和 npm run dev，Ctrl+C 或关闭终端统一停止 |

初始化按 `docs/design` 中 sql.sql、triggers.sql、views.sql、procedures.sql 的顺序执行。创建存储过程时临时对齐数据库与表的排序规则，之后恢复数据库默认值，原 SQL 文件不变。初始化和重置所需数据内置在 BAT 中。

启动前需安装前端依赖、构建后端并启动 MySQL。脚本不自动安装依赖或重置数据。启动使用 Windows Job Object 管理前后端和 npm 子进程；任一服务退出时清理整个作业。运行日志直接显示在终端。
