# 一键启动脚本说明

> 说明：本阶段仅编写文档，脚本文件在实现阶段按本文落地为 `scripts/init-db.bat` 与 `scripts/start-all.bat`（放在工作区 `scripts/` 目录）。以下为脚本设计文档与参考内容。

## 1 前置条件（一次性准备）

| 依赖 | 版本要求 | 验证命令 |
| --- | --- | --- |
| JDK | 17+ | `java -version` |
| Maven | 3.6+（或直接用工程自带 mvnw.cmd） | `mvn -v` |
| Node.js | 20+（前端 Vite 8 要求） | `node -v` |
| MySQL | 5.7 / 8.0，本地服务已启动，root 可连 | `mysql -uroot -p` |

## 2 数据库初始化（首次运行必须）

按序执行 docs/ 下四个脚本（顺序不可颠倒）：

```
mysql -uroot -p < docs/sql.sql          -- 1. 14 张表
mysql -uroot -p < docs/triggers.sql     -- 2. 3 个触发器
mysql -uroot -p < docs/views.sql        -- 3. 4 个视图
mysql -uroot -p < docs/procedures.sql   -- 4. 5 个存储过程
```

> 重复执行安全（脚本均以 `DROP ... IF EXISTS` 开头）；执行后可用
> `SHOW TABLES`（14 张）、`SHOW TRIGGERS`（3 个）、`SHOW PROCEDURE STATUS`（5 个）核对。
> 演示数据不属于初始化脚本范围：项目完成后按 [05-测试文档.md](05-测试文档.md) 单独执行 test/demo-data.sql。

## 3 启动脚本设计（两个脚本，职责分离）

> 职责约定：**初始化脚本只初始化数据库**（四个 SQL 按序执行，不含其他操作）；**一键启动脚本只拉起前后端**（不含数据库操作、不含依赖安装）。停止前后端直接关闭对应窗口即可。

### 3.1 scripts/init-db.bat（初始化脚本：仅初始化数据库）

```bat
@echo off
chcp 65001 >nul
cd /d %~dp0..
echo [1/4] 创建数据表 sql.sql ...
mysql -uroot -p < docs\sql.sql
echo [2/4] 创建触发器 triggers.sql ...
mysql -uroot -p < docs\triggers.sql
echo [3/4] 创建视图 views.sql ...
mysql -uroot -p < docs\views.sql
echo [4/4] 创建存储过程 procedures.sql ...
mysql -uroot -p < docs\procedures.sql
echo 数据库初始化完成（共需输入4次密码）
pause
```

### 3.2 scripts/start-all.bat（一键启动脚本：仅拉起前后端）

```bat
@echo off
chcp 65001 >nul
cd /d %~dp0..
echo ============ 启动后端 (Spring Boot :8080) ============
start "backend-8080" cmd /k "mvnw.cmd spring-boot:run"
echo ============ 启动前端 (Vite :5173) ============
start "frontend-5173" cmd /k "cd frontend && npm run dev"
echo 后端 http://localhost:8080 / 前端 http://localhost:5173
echo 关闭对应窗口即可停止
```

> 前置条件（脚本不负责）：① 数据库已用 3.1 初始化；② frontend 目录已执行过一次 `npm install`（含文档 03 要求的 axios、pinia）；③ MySQL 服务已启动。

## 4 手动启动步骤（不用脚本时）

```bash
# 1. 初始化数据库（首次）
mysql -uroot -p < docs/sql.sql && mysql -uroot -p < docs/triggers.sql \
  && mysql -uroot -p < docs/views.sql && mysql -uroot -p < docs/procedures.sql

# 2. 后端：工作区根目录
mvnw.cmd spring-boot:run        # 或 mvn spring-boot:run，监听 8080

# 3. 前端：新终端
cd frontend && npm install && npm run dev   # 监听 5173，/api 已代理到 8080
```

## 5 启动后验证清单

| 检查项 | 预期 |
| --- | --- |
| 访问 http://localhost:8080/api/clubs | 返回 JSON（code=0，社团数组；未登录可能 401，先登录） |
| 访问 http://localhost:5173 | 出现登录页 |
| 用预置账号登录（学生/教师） | 跳转社团广场/工作台 |
| 数据库核对 | 14 表 / 3 触发器 / 5 存储过程 / 4 视图 |

## 6 常见问题排查

| 现象 | 原因与处理 |
| --- | --- |
| 后端启动报 `Access denied for user` | application.properties 数据库账号密码错误 |
| 报 `Unknown database 'club_manage'` | 未执行 sql.sql（sql.sql 内含建库语句） |
| 前端调用接口 404 | 确认 vite.config.js 已配置 /api 代理；后端 8080 被占改端口并同步代理 |
| 报 `Table ... doesn't exist` 或 `PROCEDURE ... does not exist` | SQL 脚本未按顺序全部执行 |
| 端口占用 | `netstat -ano | findstr :8080` 定位进程；或改 server.port 与 Vite 代理 |
| 存储过程报 45000 业务错误 | 属正常业务拦截（如重复申请），前端应展示该 message |
| 首次 mvn 下载依赖很慢 | 配置 Maven 镜像（阿里云）到 settings.xml |
| 前端 npm run dev 报 Node 版本错误 | Vite 8 需 Node 20+，升级 Node |

## 7 演示数据（实现阶段）

初始化完成后，按 [05-测试文档.md](05-测试文档.md) 第 2 节蓝图生成 test/demo-data.sql（学生 10 名含 5 人建团组与 2 名学生会成员、教师 3 名 2 空闲 1 绑定），执行：

```
mysql -uroot -p club_manage < test\demo-data.sql
```

演示剧本见 05 文档第 4 节：登录 → 建团双审批（驳回/通过各一次）→ 入社审批 → 晋升/换届 → 活动申办审批 → 公告/消息发布 → 解散双审批（观察社团数据被删除）。
