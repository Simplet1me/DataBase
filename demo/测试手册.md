# 演示与测试手册

## 准备与启动

环境：Windows、Java 17+、Node.js 22.12+、MySQL 8。MySQL 服务需先启动；Maven 可安装到 PATH，也可使用项目自带的 Maven Wrapper（首次构建需要联网）。

1. 在 `frontend` 目录执行 `npm ci` 安装前端依赖。
2. 在项目根目录执行 `demo\database_init.bat`，创建 `club_manage`、数据库对象及测试数据。已有数据表时停止，不覆盖。
3. 执行 `demo\build.bat`，仅构建后端，输出 `release\club-manage.jar`。
4. 执行 `demo\start.bat`，浏览器访问 http://localhost:5173 。后端 `java -jar` 和前端 `npm run dev` 共用当前终端显示日志。
5. 按 Ctrl+C 或关闭运行终端，前后端及 npm 子进程一起退出。任一服务退出也会停止另一服务。

默认 MySQL：`127.0.0.1:3306`，账号 `root`，密码 `123456`。数据库脚本支持 `DB_HOST`、`DB_PORT`、`DB_USER`、`DB_PASSWORD`，客户端可用 `MYSQL_BIN` 指定 `mysql.exe` 完整路径。后端支持 `DB_USER`、`DB_PASSWORD`；使用其他数据库主机/端口时同时设置 `DB_URL`（完整 JDBC URL，库名为 `club_manage`）。启动使用 8080 和 5173，端口占用会报错退出。

需要重新演示时，先停止服务，再运行 `demo\database_reset.bat`，输入 `RESET`。这会删除并重建 **club_manage**，恢复下列账号和预置篮球社，其他数据库不受影响。取消输入不会修改数据库。

## 基本测试步骤

按顺序执行；每次切换账号先退出登录。

1. **登录与权限**：输入错误密码，应提示登录失败；2021010 登录后可见社团广场、个人中心等学生页面，不能进入社团管理和学生会页面。
2. **社团查询**：在社团广场搜索“篮球”，打开详情，应显示教师、人数和公告；清空搜索恢复列表。
3. **入社审批**：2021010 申请加入篮球社，在个人中心看到待审批记录。切换 2021006，在入社审批中同意；2021010 再登录，应有篮球社档案。重复申请应被拒绝。
4. **退社**：2021010 在个人中心退出社团，当前社团身份消失，历史记录保留。
5. **建团**：2021001 发起建团，填写新社团名称、简介、T001，以及 2021002～2021005。2021007 在双审工作台同意，T001 在教师工作台同意。2021001 再登录，应可管理新社团，五名发起人的角色正确。
6. **活动**：2021006 在篮球社活动管理中申办活动，填写名称、简介、开始/结束时间及地点。T003 同意后，活动显示为进行中；2021006 可结束活动。结束早于开始的时间应被拒绝。
7. **公告**：2021008 发布、编辑篮球社公告，在社团详情核对内容；删除后详情不再展示该公告。
8. **系统消息**：2021007 发布、编辑、删除系统消息，切换普通学生在消息中心核对。
9. **学生会成员**：2021007 添加 2021010，后者重新登录后可访问学生会功能；移除后权限消失。至少保留一名学生会成员。
10. **换届**：2021006 在社员管理中将自己加入降级名单，选择 2021008 为新社长。完成后重新登录核对两人的角色和角色变更记录。
11. **解散**：2021008 发起篮球社解散申请，2021007 与 T003 依次同意。社团从广场消失，成员解除社团归属，T003 不再指导篮球社。
12. **停止与重启**：按 Ctrl+C，确认 8080、5173 均不再监听，刷新网页不可用。重新运行 `start.bat` 应正常启动，数据保留。再关闭运行终端，同样确认两个服务停止。

可在 PowerShell 检查端口：`Get-NetTCPConnection -State Listen -ErrorAction SilentlyContinue | Where-Object LocalPort -in 8080,5173`。

## 常见问题

- 缺少 JAR：先运行 `build.bat`；缺少 Vite：在 `frontend` 执行 `npm ci`。
- MySQL 连接失败：检查服务、连接参数及 `MYSQL_BIN`。
- 初始化提示已有表：直接启动；确需丢弃现有数据时使用重置脚本。
- 端口已占用：停止原有服务后再启动。
